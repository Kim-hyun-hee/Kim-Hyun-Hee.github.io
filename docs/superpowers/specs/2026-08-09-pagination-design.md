# 페이지네이션 재설계

작성일: 2026-08-09
선행 문서: `2026-08-09-link-card-design.md`

## 1. 배경

기존 페이지네이션은 글자 한 줄이었다.

```
이전   1 / 3   다음
```

테두리도 배경도 없고 페이지 번호를 누를 수도 없었다. 업스트림 기본값 그대로였고,
사용자가 "못생겼다"고 지적했다.

## 2. 크기를 두 번 정한 이유

처음에는 44px 정사각형에 솔리드 배경으로 만들었다. 실물로 보니 목록 아래에서
덩어리처럼 무거웠다. 36px로 줄이고 현재 페이지를 연한 틴트로 바꾸니 목록의
리듬을 끊지 않았다.

숫자를 두 자리로 채우는 것(`01`)도 이때 정했다. 한 자리와 두 자리가 섞이면
칸마다 글자 너비가 달라 보여 줄이 흔들린다.

## 3. 결정한 모양

| | 값 |
|---|---|
| 크기 | `size-9` (36px) |
| 모서리 | `rounded-md` |
| 글자 | `text-xs font-bold` (12px) |
| 간격 | `gap-2` (8px) |
| 번호 | `01`, `02` — 두 자리로 채움 |
| 기본 | `text-muted-foreground` |
| hover | `hover:bg-muted hover:text-foreground` |
| 현재 페이지 | `bg-accent-muted text-accent` |
| 이전·다음 | 화살표 아이콘만. 텍스트 라벨 없음 |
| 비활성 화살표 | `<span aria-hidden="true">` — 링크가 아니다 |

**현재 페이지를 솔리드로 채우지 않는다.** 연한 틴트 배경에 보라 글자를 쓴다.
솔리드는 목록 아래에서 지나치게 튀었다. 우리는 그 짝을 이미 토큰으로 갖고 있어
(`--accent-muted` / `--accent`) 값만 연결했다.

**hover 배경은 유지하되 무채색이다.** `--muted`는 채도 0%라 회색 배경이 파랗게
비치지 않는다. 회색 토큰에 색을 섞지 않는 팔레트 원칙이 여기서도 그대로 적용된다.

**비활성 화살표를 `<a href="#">`로 두지 않는다.** 링크가 아닌 것을 링크로 만들면
스크린리더가 이동 가능한 것으로 읽고 Tab 순서에도 들어간다. `<span>`으로 두고
`aria-hidden`을 붙인다.

## 4. 번호 접기

한 번에 최대 7칸을 보여준다. 첫 페이지, 마지막 페이지, 현재 페이지는 항상
포함하고 나머지를 `…`으로 접는다.

```
1 2 3 4 5 6 7          (7페이지 이하)
1 2 3 4 5 … 20         (앞쪽)
1 … 9 10 11 … 20       (가운데)
1 … 16 17 18 19 20     (뒤쪽)
```

**`…`은 클릭할 수 없다.** 점을 눌러 중간 페이지로 뛰게 만드는 방식도 있으나,
눌러서 어디로 갈지 예측할 수 없는 동작이라 뺐다.

## 5. 순수 함수 두 개

`src/utils/pagination.ts`에 두 함수를 두고 테스트했다.

**`getPaginationItems(current, lastPage)`** — 위 접기 규칙. 속성 기반으로
검사한다: 항상 7칸 이하, 현재·첫·마지막 페이지를 항상 포함.

**`getPageBasePath(currentUrl, currentPage)`** — 주소에서 페이지 번호를 떼어
기본 경로를 얻는다. 번호별 링크를 만들려면 필요하다.

경계가 하나 있다. 경로 자체에 숫자가 들어간 분류(`/categories/2024-notes/`)가
있을 수 있으므로 무조건 마지막 조각을 떼면 안 된다. **현재 페이지 번호와 일치할
때만** 뗀다.

## 6. 주소를 한 곳에서 만든다

이전·다음 링크도 번호와 같은 `urlFor()`로 만든다. Astro가 주는 `page.url.prev`는
끝 슬래시가 없어서(`/posts`) 그대로 쓰면 번호 링크(`/posts/`)와 **같은 페이지에
두 가지 주소**가 생긴다.

## 7. 명암비에 대해

라이트에서 현재 페이지는 `#8387d3` on `#f4f5fe` = **3.04**, 다크는 `#767bd0` on
`#232536` = **3.97**이다.

본문 텍스트 기준(4.5)에는 못 미친다. **여기서는 그 기준을 적용하지 않기로 했다.**
페이지네이션 숫자는 짧고, 위치로 예측 가능하며, 현재 페이지가 배경으로 구분되어
맥락이 있다. 사용자가 라이트·다크 양쪽을 실물로 확인하고 판단했다.

기준을 지켜야 하는 자리는 따로 있다 — 본문 글자와 사이드바 링크다. 그쪽은
`2026-08-09-neutral-palette-design.md`에서 전부 맞췄다.
