강조색을 하나 정하고 링크·활성 메뉴·포커스 링에 전부 쓰다가, 화면이
산만해져서 되돌렸다.

## 먹색 하나로

강조 토큰에 본문과 같은 먹색을 넣고, 구분은 굵기와 밑줄로 냈다.

## 파랑은 남겨둠

없앤 게 아니라 별도 토큰에 보관했다. 되돌리려면 값 하나만 바꾸면 된다.

```css
--accent: #1e1f21; /* UI 강조 = 본문색 */
--brand: #246d8f; /* 보관용. 지금은 어디에도 쓰지 않는다 */
```
